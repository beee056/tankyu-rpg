## 0. 用語と共通仕様

### 0-1. 演出ディレクティブ表記

各ビート（B##）に以下の項目を必ず記載する。

| キー | 意味 |
|------|------|
| `scene_id` | 既存の SceneData.scene_id（テキストの出典） |
| `bg` | 表示する背景画像（前ビートからの継承時は "(継承)"） |
| `bg_fx` | 背景の入り（`fade_in 800ms` / `crossfade 1200ms` / `none`） |
| `chars` | 表示中の立ち絵（`[char]:[pose]:[position]`、入退場含む） |
| `char_fx` | 入退場アニメ（`slideIn left 400ms` / `slideOut right 300ms` / `fadeIn 500ms`） |
| `bgm` | BGM操作（`start bgm_main 2000ms fadeIn` / `(継続)` / `stop 1500ms fadeOut`） |
| `se` | このビートで鳴らす SE（`se_door` / `se_evidence` 等） |
| `text_pacing` | 句読点ウェイト ms / 改行ポーズ ms（既定 `comma=120 / period=240 / newline=400`） |
| `extra_fx` | カメラ・ビネット・章タイトル等の特殊演出 |

## 4. 証拠取得カード演出

`ev_ch1_01` / `ev_ch1_02` 取得時の共通演出：

1. `se_evidence.mp3` を再生（vol 60%）
2. 画面右上に 192×160 のカードが `slideIn from-right 400ms ease-out + scale 0.92→1`
3. カード内: 上にタイトル（白）、下にスニペット2行
4. 1500ms 維持後 `fadeOut 400ms`
5. 左上の証拠バッジカウントが +1（`bounce 300ms`）
6. ハイライト下線の `text-shadow` 解除

## 5. 立ち絵レイアウト規約

- キャンバス: 16:9、立ち絵高さ = 画面高 78%（バストアップ）/ 92%（全身）
- 縦位置: 画面下端 +4%
- 横位置: `left = +8%` / `center = 中央` / `right = -8%`
- 同時2人最大、3人目で最初の1人を退場
