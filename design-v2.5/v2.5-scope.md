## 1. 背景

v2 MVP は機能としては動作したが、以下の理由で「面白くない」状態に陥った。

- 黒い背景＋立ち絵＋テキスト送りだけで、画面が動かない
- 全シーン同じ見た目で、章の進行感がない
- ダッシュボードが「枠と文字」だけで、ゲームを起動する高揚感がない
- 灰島の立ち絵が全身で、画面に対してスケールが浮いている

KOL記事 / Verdent 紹介でデモする以上、「最初の3分」で見るに堪える完成度が必須。そこで章8コマ全部を捨て、冒頭だけを徹底的に磨くことに決定する。

## 4. scene_02 前半の終端（明示）

`ch1_s02_collect_choice` の3択を**画面に表示はする**が、どれを選んでも次のシーンには進まず「To be continued — このデモはここまで。続きは次章で。」というカードがフェードインして固定表示になる。

```
ユーザーが「みのりにもっと話を聞く / SNS投稿を調べる / 親友の側に話を聞く」のいずれかをタップ
  ↓
選択肢のフラグ・証拠付与は実行（記録される）
  ↓
"To be continued" カードが表示され、ダッシュボードへ戻るボタンを提示
```

**実装イメージ**: `ch1_s02_collect_choice` の各 choice の `next_scene` を `ch1_s02_to_be_continued` に向ける、新しい `to_be_continued` シーンを `scenarios/ch1/scene_02.ts` 末尾に1ノード追加。

## 5. 完成イメージ

> 「Verdent KOL 記事や友人にURLを送って、10分で冒頭体験できる触れるデモ。坂を上がり、ヨアケのドアを開け、灰島・知深・御堂・みのりに出会い、最初の証拠を2枚集めるところまでをノベルゲームらしい演出で見せる」

到達基準：

1. ダッシュボードを開いた瞬間に「事務所に来た」感がある（マップ・温かい光・BGM）
2. プレイ開始時に章タイトルがフェードインする
3. 坂 → ヨアケ外観 → 事務所内 と背景が切り替わる
4. キャラ立ち絵が左右からスライドイン、退場アニメで現れる
5. ev_ch1_01 / ev_ch1_02 のタップ取得時にカード演出と SE が鳴る
6. テキスト送りに句読点ウェイトが効いている
7. scene_02 前半の "To be continued" まで、画面が暗いだけのコマがゼロ
